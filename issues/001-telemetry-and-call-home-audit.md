# Audit Report: Call-Home & Telemetry Mechanisms in `prime-agent`

This document details all discovered locations where the agent / harness initiates outbound network connections ("calls home"), what data is transmitted, and step-by-step instructions for disabling or completely removing these behaviors.

**Status:** Resolved (Telemetry defaulted to disabled / opt-in)

---

## 1. Summary of Outbound Network Calls

| Location | Purpose | Data Sent / Endpoint | Opt-Out Flag / Environment Variable |
| :--- | :--- | :--- | :--- |
| **Product Analytics & Telemetry**<br>`packages/coding-agent/src/core/telemetry.ts` | Usage & performance telemetry | `installation_id` (UUID), OS/arch, install method, event name, timing, token counts, cost, error categories, provider/model categories.<br>**Endpoint:** `https://api.primeintellect.ai/api/v1/agent-analytics/events` | `DO_NOT_TRACK=1`<br>`PI_OFFLINE=1`<br>`PRIME_AGENT_TELEMETRY=0`<br>Settings: `telemetry.enabled = false` |

## 2. Detailed Findings

### A. Product Analytics Telemetry (`telemetry.ts`)
- **File Location:** [`packages/coding-agent/src/core/telemetry.ts`](../packages/coding-agent/src/core/telemetry.ts)
- **Events Captured:**
  - `agent started`
  - `onboarding completed`
  - `agent command used`
  - `agent run completed`
  - `agent session ended`
- **Data Transmitted:**
  - `installation_id`: Randomly generated UUID stored in `~/.prime-agent/telemetry.json` (or custom `agentDir`).
  - `os_family`, `architecture`, `install_method`, `execution_mode`.
  - Session and run statistics: token counts (input, output, cache read/write, total), duration, latency, TTFT, tool call counts, error category, sanitized provider/model category (`anthropic`, `claude`, `openai`, etc.).
  - **Note:** Prompt text, LLM completions, tool content, file paths, and git repo contents are **NOT** sent.

### B. Auto-Update / Version Checking (`version-check.ts`)
- **File Location:** [`packages/coding-agent/src/utils/version-check.ts`](../packages/coding-agent/src/utils/version-check.ts)
- **User-Agent Header Sent:** Generated by [`packages/coding-agent/src/utils/pi-user-agent.ts`](../packages/coding-agent/src/utils/pi-user-agent.ts)
  ```
  prime-agent/<version> (<platform>; <runtime>; <arch>)
  ```
- **Data Transmitted:** HTTP `GET` request containing system User-Agent header requesting version manifest JSON files.

## 3. How to Disable Call-Home Features (Configuration / Environment)

To disable all telemetry and version check calls without modifying source code, set the following environment variables in your shell profile:

```bash
# Disable analytics telemetry
export DO_NOT_TRACK=1
export PRIME_AGENT_TELEMETRY=0

# Disable auto version check
export PI_SKIP_VERSION_CHECK=1

# OR: Enable complete offline mode (disables both version checks & telemetry)
export PI_OFFLINE=1
```

Alternatively, disable telemetry via configuration settings file (`~/.prime-agent/settings.json`):

```json
{
  "telemetry": {
    "enabled": false
  }
}
```

## 4. How to Completely Remove Call-Home Code

If hard removal of telemetry and phone-home logic from the codebase is required:

1. **Disable Telemetry Client Invocation:**
   In [`packages/coding-agent/src/core/telemetry.ts`](../packages/coding-agent/src/core/telemetry.ts#L204), update `isTelemetryEnabled` to always return `false`:
   ```ts
   export function isTelemetryEnabled(_settingsManager: SettingsManager): boolean {
       return false;
   }
   ```

2. **Disable Version Check Requests:**
   In [`packages/coding-agent/src/utils/version-check.ts`](../packages/coding-agent/src/utils/version-check.ts#L118), return `undefined` immediately in `getLatestPiRelease`:
   ```ts
   export async function getLatestPiRelease(
       _currentVersion: string,
       _options: { timeoutMs?: number } = {},
   ): Promise<LatestPiRelease | undefined> {
       return undefined;
   }
   ```
